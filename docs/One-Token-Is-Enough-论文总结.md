## 一、背景与动机

### 1.1 问题：不透明推理服务链中的模型替换

LLM 推理市场已高度分层：模型创建者与应用终端之间插入了推理提供商、转售商和聚合器（如 OpenRouter）。客户端只凭一个**字符串（模型名）**寻址模型并收到文本——整个交换过程**没有任何证据证明广告中的模型真的产生了答案**。提供商可能：

- 替换为更便宜的模型；
- 使用激进量化变体；
- 回退到旧版本；
- 赚取差价。

### 1.2 现实证据（非假设性担忧）

- Gao et al. [1]：31 个服务 Llama 的商业端点中，**11 个**输出分布与厂商参考权重统计上不兼容；
- Cai et al. [2]：形式化"模型替换威胁"，证明朴素输出比对在生产级非确定性下很脆弱；
- Zhu et al. [3]：对量化变体提出同样担忧；
- 经济激励是结构性的：推理成本随量化与模型尺寸骤降，而检测风险迄今很低。

### 1.3 现有方法的短板

| 方法类型 | 代表工作 | 短板 |
|---|---|---|
| 生成文本的分类归属 | Uchendu et al. [7]、Sun et al. [8]（五路 97% 准确率） | 需要**长输出** |
| 查询高效的主动探针 | LLMmap [9]（8 个工程化查询识别 42 个版本）、TRAP [10] | 依赖精心构造/对抗优化的提示，**可被自适应提供商识别并特殊对待** |
| 统计等价性检验 | Gao et al. [1] | 消费完整采样字符串，且假设有同模型参考部署做校准 |
| 合作式（白盒）方案 | 解码时水印 [4]、指令后门 [5]、FIT-Print [6] | 服务**模型所有者**；第三方审计客户端无法部署 |

**客户端约束**：无权重/无 logits（许多 API 只返回文本）、无法微调或加水印（排除合作技术）、预算极低（持续审计必须花美分而非美元）。

## 二、核心思想

> **从一个"缺陷"反转出取证信号**：LLM 被要求"随机"选数字时，表现出可靠且特异的非随机性 [11–14]。本文不把这当好奇心，而是当作**法证信号**。
>
> **文献基础（行为学/单文化研究）**：行为经济学研究显示 LLM 在博弈中表现出系统、模型特异的倾向 [19]；共享训练语料会在不同部署间产生共享先验与同质化结果（算法单文化）[20, 21]，呼应人类经典的焦点行为研究 [22, 23]。本文贡献**逆向视角**：这些偏差中任何系统性且模型特异的部分都是**身份**——且采样身份只需一个 token，取证价值极高。

- 提示如 *"Name a random number between 1 and 100"* 只消耗几十个输入 token + **恰好 1 个输出 token**；
- 但答案在重复采样下的**经验分布**是一个丰富、稳定的对象：它反映 tokenizer 结构、训练数据先验、后训练选择——被替换的模型无法精确复现；
- 信号是**无害日常问题上的分布**，而非"魔法字符串"：采集便宜、对提示改写鲁棒、且不诚实的提供商难以在不整体仿冒目标模型的前提下特殊化处理。

**三个关键洞察**：
1. 指纹不依赖长文本、log-prob、对抗提示或模型所有者合作；
2. 量化/蒸馏恰好扰动这些探针采样的**最终 softmax 景观**——所以指纹对商业上重要的替换敏感，而对不重要的服务栈细节不敏感；
3. 多语言设计还能捕获跨模型共享的文化先验（留作配套研究的隐性协调分析，本文仅把语言当作独立探针维度）。

## 三、研究问题（RQ）

| 编号 | 问题 |
|---|---|
| **RQ1** | 单 token 答案分布是否构成**稳定**的模型指纹——跨服务提供商、采样温度、时间不变，而跨模型有区分度？ |
| **RQ2** | 指纹间距离能否恢复**谱系**——模型按已知家族聚类，未见模型的家族能否仅凭指纹分类？ |
| **RQ3** | 给定 k 个探针查询，对"此端点服务模型 X"的声明验证有多可靠（生物特征风格 ROC/EER），随查询预算如何伸缩？ |
| **RQ4** | 应用于生产聚合器生态，指纹揭示哪些**异常**——行为偏离其声明模型的端点？ |

## 四、方法论

### 4.1 指纹定义

- 探针电池 **B = {(t, ℓ)}**：任务 t × 提示语言 ℓ（**10 任务 × 4 语言 = 40 个 cell**）；
- 每个 cell 以 **温度 1.0** 查询 n 次，固定系统提示强制一词回答，**16 token 上限**（预注册原定 12，因多家厂商端点直接拒绝 12 而上调至 16；有效答案本就为 1–6 token，不影响任何分布），禁用 provider 端推理模式——保证 completion 是模型条件分布的**直接单遍采样**；
- 回答归一化：Unicode NFC、标点/引号剥离、大小写折叠、阿拉伯-印度/中文数字映射到拉丁数字、取首个 token、按语言颜色词表映射为规范编码；
- 每个回答分类为 valid / invalid / refusal / empty，**无静默丢弃**（总体有效率 97.6%；逐模型中位数 99.6%，最低 60.6%——一个常以整句作答的模型）；refusal 率与有效率本身是弱身份信号，但**被排除在指纹之外**以保持对安全层变化的鲁棒性；
- **指纹** F(M) = (p̂ᵀ_{t,ℓ})₍ₜ,ℓ₎∈B，并附带温度 0 的确定性变体。

**任务清单（Table I）**：随机数 1–100（闭）、随机数 1–10（闭）、最喜欢的数字（开）、随机字母（闭）、随机词（开）、随机颜色（开）、最喜欢的颜色（开）、随机动物（开）、随机城市（开）、抛硬币（闭，2 值）。

选择标准：(i) 允许单 token 回答；(ii) 覆盖闭空间（数字、硬币）与开空间（词、城市），携带互补信号；(iii) 包含 random/favorite 对比（本身有区分度 [14]）；(iv) 四种语言（英/俄/中/阿）文化中性，以零设计成本乘出探针维度、探测训练先验的不同切片。

### 4.2 分析单元

- **checkpoint**：被指纹化的对象（同一权重可能以滚动别名 `-latest`、日期快照、免费层 `:free`、推理模式变体等身份暴露）；
- **endpoint**：通往某个声明 checkpoint 的一条服务路径；
- **family**：共享祖先的 checkpoint 谱系。

### 4.3 距离与谱系分析

- **距离**：逐 cell 的 Jensen–Shannon 散度（基 2）在双方均 ≥10 有效样本的 cell 上取平均：

  D(Mₐ, M_b) = (1/|B′|) Σ₍ₜ,ℓ₎∈B′ JSD(p̂ᵃₜ,ℓ ‖ p̂ᵇₜ,ℓ)

- JSD 对称、有界 [0,1]，对稀疏分类分布良好定义（支持不相交也可用）；
- **RQ2 两步**：
  1. UPGMA 平均连接层次聚类，在与家族数同一切点处用 **adjusted Rand index (ARI)** 与已知家族对比；
  2. **留一法最近邻（LOO 1-NN）**分类每个模型的家族。

### 4.4 验证协议（生物特征风格）

- **Enrollment**：从可信部署采集模型 X 的参考指纹；
- **Audit**：从电池（或其改写家族）采样 k 个探针 cell，每 cell 收集 n 个回答，计算得分 s = (1/k) Σ JSD(p̂_ref ‖ p̂_E)，若 **s ≤ τ 则接受**声明；
- **评估**：
  - *genuine trials*：同一模型样本的两半（按重复奇偶切分，时间交错）；
  - *impostor trials*：模型 X 的一半 vs 模型 Y 的一半（Y ≠ X）；
  - 扫 τ 得 ROC、AUC 与**等错误率 EER**；
  - 重采样随机 k 子集得 **query-budget 曲线**（EER 作为探针 cell 数的函数）——即给定保证等级的操作成本；
  - 用 OpenRouter 路由提供的自然实验（同模型不同 provider）检验指纹对服务栈的鲁棒性。

### 4.5 实现

- 对 OpenRouter 聚合器 API 的可恢复、幂等采集器：每次请求是确定性 cell 重复；失败指数退避重试且不入数据；每条响应原样存储（UTC 时间戳、延迟、服务提供商、报告模型串、token 用量含缓存计数、成本）；
- cell 以种子打乱顺序执行，速率限制亏空近似均匀扩散（设计上随机缺失），逐 cell 分析要求 ≥10 有效样本；
- 全量数据、代码、配置以开放数据集发布（Zenodo [24,25]），假设与分析计划预注册（OSF [26]）。

## 五、实验设置

- **模型池**：OpenRouter 目录快照（2026-07-06，342 模型）经**机器可查的排除规则**筛选 → **165 个模型、19 个家族标签、53 个服务提供商**；
- 排除项：非纯文本对话模型、窄域专用模型（代码/数学/医疗/角色扮演）、非单一稳定 checkpoint（滚动 latest 别名、可变预览/弃用端点、元路由、多智能体/检索接地管线、免费层/推理模式重复）、**强制隐藏推理阶段**的端点（含目录元数据未标注、采集前事后发现的 OpenAI o-series——其拒绝 reasoning effort "none"，无法禁用推理）、仅免费层端点（账户级每日请求上限使完整采集不可行）、以及一个人工记录排除（$150/$600 定价）；
- **采样**：每模型 × 10 任务 × 4 语言，T=1.0 采样 30 次 + T=0 采样 3 次；前沿定价模型（≥$5/1M 输入 token）T=1.0 采样 15 次；
- **试点与预注册**：14 个模型（7 对同族大+小对）试点固定全部设计与分析选择（有效率 ≥80%、provider 内贪婪确定性 ≥90% cell、族间-族内散度缺口显著 p=0.0008、成本外推）；假设与分析计划在主运行前预注册，试点数据排除在确认性分析之外；
- **采集损耗**：165 个普查模型中 163 个达到 ≥95% 期望重复次数，2 个（91–94%）保留全部 40 个 cell 高于每 cell 最低样本要求；5 个目录端点全程不可达、1 个系统性失败（详见 8.4）；
- **成本**：326,047 个响应（23.3M 输入、1.16M 输出 token），总成本 **$34.44，即 $0.21/模型**——在相同重复次数下比长文本归属**低约三个数量级**。

## 六、主要结果

### RQ1：指纹存在且稳定

- **高度非均匀**：6,572 个 cell（≥10 有效样本）中位数熵 **1.00 bit**、中位数众数占比 **0.71**（均匀基线 1–6.6 bit；如随机数 1–100 为 6.64 bit）；
- **模型特异且可复现**：同模型两半的 cell 级 JSD 中位数 **0.075** vs 不同模型 **0.489**（6,564 个 genuine 对 107 万 impostor 对）；
- **温度 0**：90.4% cell 在 provider 内确定性；跨 provider 池化降至 84.5%——差额即服务栈方差（同模型不同上游部署产生不同但各自稳定的贪婪答案）；
- **跨 provider 鲁棒性**（31 个模型由 ≥2 provider 服务，34 个 provider 对）：跨 provider 距离中位数 **0.227**——高于单部署分裂半噪声底线（0.140）但远低于 impostor 中位数（0.463），70.6% 的 provider 对低于 impostor 距离第 5 百分位；**跨 provider 验证 AUC = 0.880**（同 mix 0.971）；
- 图 1 直观示例：同一提示，GPT-4o 分散于 42/37/57，Claude Sonnet 5 集中于 47，Llama 3.3 集中于 53，Qwen3-Max 每次都答 42。

### RQ2：谱系恢复

- UPGMA 聚类忠实还原距离结构（**cophenetic 相关 0.886**）；
- **LOO 1-NN 家族分类：59.5%**（163 个有同族样本的模型），vs 频率加权随机基线 18.4%（**3.2× 随机**，精确二项 p < 10⁻³⁰）；
- 在 k=19 处的平面切割只弱恢复家族（ARI = 0.023）——**谱系信号存在于最近邻几何中，而非全局紧凑簇**（标签集含 17 模型"other"杂袋与若干单例）；
- 主要谱系恢复良好（论文 Table II，≥8 成员家族，精确率/召回率）：GLM 1.00/0.83、Mistral 0.87/0.81、Llama 0.88/0.58、GPT 0.70/0.90、Qwen 0.50/0.73、Claude 0.54/0.58、DeepSeek 0.46/0.75、Gemini 0.43/0.55；异构"other"标签自然不行（0.20/0.06）。

### RQ3：验证与查询预算

- 全电池：**AUC = 0.971，EER = 7.3%**（165 genuine / 27,060 impostor trials）；
- 查询预算曲线：1 个 cell 即远超随机（EER 23.3%）→ 4 个 13.2% → **8 个 10.6%** → 16 个 9.5% → 32 个 8.4% → 40 个 7.3%；k ≈ 16–24 后曲线趋平；
- k=16 操作点：按估计所用的样本量（每 cell 15 次重复）审计成本为 **16×15 = 240 个单输出 token 查询，约 16k 输入 token**——典型定价模型百分之一美分到前沿模型几美分，**持续再审计经济上微不足道**。

### RQ4：生态异常（均为统计陈述，非意图指控）

- **身份异常**：
  - `writer/palmyra-x5`（被营销为厂商专有旗舰模型）的指纹与 `qwen/qwen3-235b-a22b-2507` 距离 **0.141**——处于 genuine 同模型距离中位数（0.140），远低于 impostor 区间，即**与开源 Qwen 部署分布不可区分**；
  - 谱系证实但未标注：`deepcogito/cogito-v2.1-671b`（DeepSeek V3 底座训练）最近邻落在三个 DeepSeek checkpoint（0.268–0.308，低于 impostor 第 5 百分位）；多个"other"厂商模型（`xiaomi/mimo-v2.5-pro`、`inclusionai/ling-2.6-1t`）深入 Qwen 邻域；
  - 信号也可被**抹除**：`nvidia/llama-3.3-nemotron-super-49b-v1.5`（有记载的 Llama-3.3 衍生）更接近 Qwen（0.303）而非任何 Llama——重度后训练覆盖谱系先验，约束了家族分类的承诺边界；
- **部署异常**：34 个同模型 provider 对中 **10 个（29%）偏离超过 impostor 距离第 5 百分位**——服务分布差异超过两个不同模型的典型差异；极端案例 `llama-3.2-3b-instruct` Cloudflare vs Parasail 达 0.716（深入 impostor 区间），甚至 `gpt-4` 经 Azure vs OpenAI 第一方也达 0.392；
- **服务层不透明**（内容盲审计不可见）：旗舰聊天端点每个一词可见回答消耗 ~40–60 个 completion token；0.76% 响应携带推理轨迹（14 个模型-provider 组合，共 2,486 条）——provider 静默忽略 reasoning-disable 标志；此类响应**单列一类、永不进入指纹**；一个模型在**所有数字提示**上唯一 provider 返回服务器错误而其余正常。

## 七、威胁模型

**场景**：客户端向不信任的 provider（可能经聚合器路由）购买声明模型 X 的推理。Provider 全栈控制服务：可忠实服务 X、服务量化/降级变体 X′、替换更便宜模型 Y、或动态路由。

**验证者能力**：(i) 发送普通聊天请求（可选 system/user 提示、温度、token 上限、标准解码选项如禁用可选推理模式）；(ii) 观察返回文本与标准元数据；(iii) 查询可信的 X 参考部署以登记参考指纹。**无 logits、无权重，单次审计预算最多几百输出 token。**

**对手三层**：

| 层级 | 行为 | 协议应对 |
|---|---|---|
| T1 oblivious | 静默替换，不检查流量 | **完全防御** |
| T2 filtering | 识别已知审计提示（如已发布的逐字提示）并路由到真 X | **设计上防御**：探针空间是日常问题的开放式改写家族，审计时采样；提示与普通流量不可区分，使过滤在检测论上昂贵 |
| T3 emulating | 试图在任意低熵提示上复现 X 的答案分布 | **崩溃为忠实性问题**：在任意提示上匹配 X 的条件分布约等于运行 X；蒸馏到该保真度侵蚀替换利润 |

不声称密码学保证：协议**提高**未被发现的替换成本，补充基于硬件证明的方案 [2]。

## 八、讨论

### 8.1 为何单 token 分布携带身份

一词回答的分布聚合了模型构建的多层：tokenizer 对候选答案的切分、预训练语料频率、指令微调与偏好优化偏移、解码实现。**量化与蒸馏恰好扰动这些探针采样的最终 softmax 景观**——这解释了为什么指纹对商业上重要的替换敏感、而对不重要的服务栈细节不敏感（经验上替换 provider 只移动中位数 0.227，不足 impostor 中位数 0.463 的一半）。

### 8.2 自适应 Provider（T2）

电池**按构造不含魔法字符串**：任务是语义类别（说一个随机颜色/数字/城市），允许无界改写与翻译（电池自身已实现 4 种语言）；指纹是答案分布的性质，而非任何特定措辞的性质。专用改写不变性实验留作未来工作。

### 8.3 服务层缓存

- **前缀缓存不是混淆因素**：13.4% 请求命中 prompt-cache（覆盖 10.1% 输入 token），但它只复用已见输入前缀的确定性 KV 计算，改变成本与延迟而不改变解码条件分布，重复采样仍是同分布的独立抽取；
- **响应级缓存**（重放已存 completion）会人为压垮 T=1.0 分布——在威胁模型内这**本身是端点完整性违规**，留下联合签名：T=1.0 响应方差崩溃 + 异常低且低方差的延迟。全普查筛查：2,040 个 T=1.0 单答案 cell 中仅 14 个同时具备低于其模型一半的中位延迟，且都处于可归因于 provider 负载波动的正常亚秒延迟——**未发现响应级缓存签名**；命中该筛查的 cell 按异常处理而非指纹证据。

### 8.4 局限性

1. 指纹随模型更新漂移，参考登记需刷新；只量化了短期稳定性，未量化多月漂移；
2. 验证假定**可信参考部署**；
3. 极低流量 provider 每 provider 样本少；
4. 采集窗口内 5 个目录端点不可服务（退役 serverless 部署、两家持续宕机、两个"unknown model"）+ 1 个模型唯一 provider 在所有数字提示上系统性失败——按损耗报告而非分析；
5. 封闭厂商家族标签依赖公开文档，标签噪声只会**压低**（不会抬高）谱系结果；
6. **强制隐藏推理的端点被排除**：推理阶段后输出的答案采样自不同于直接单 token completion 的生成过程，混池会按协议而非谱系聚类。标准最终是**行为的而非声明的**：采集发现宣称推理可选却忽略禁用标志的端点、以及无推理轨迹却多耗几倍 token 的旗舰端点——后者无法证明答案是直接单遍采样，故同标准排除（观测到的隐藏 token 开销本身是生态观察）；
7. 普查只覆盖一个聚合器；协议与聚合器无关，但生态发现可能不泛化。

## 九、伦理与负责任披露

- 在付费配额内用普通聊天请求探测商业端点无同意问题，不涉及个人数据；
- 生态异常作为**服务分布与参考部署之间的统计偏差**报告——而非欺诈指控（良性原因如权重更新、受认可量化、缓存层都能产生偏差）；
- 发现**不是安全漏洞**：发表不使能任何攻击、无漏洞可打补丁，故协调披露规范不适用，未运行发表前通知流程；
- 问责靠透明：每个发现附良性解释；发布的原始数据（逐请求时间戳、服务提供商、生成标识）允许任何具名或第三方独立验证或反驳；受影响方的实质澄清会纳入修订版；
- 武器化价值低：只揭示公开行为之外无模型内部信息；共享先验测量的双重用途（跨模型协调）在配套研究中讨论。

## 十、结论与未来工作

> **模型身份通过最便宜的信道泄露：被问琐碎问题时模型吐出的单个 token。**

本文证明此类 token 的分布能指纹化 LLM、重构其谱系，并支撑一个实用、改写鲁棒的验证协议及其可靠性-成本曲线。随着推理市场深化、广告模型与服务模型之间的差距成为常规诚信问题，单 token 审计提供了**可部署、近零成本**的取证工具。

**未来工作**：
- 纵向漂移追踪；
- 水印感知变体；
- 配套研究：共享指纹结构对模型间隐性协调意味着什么（预注册 [26]）。
